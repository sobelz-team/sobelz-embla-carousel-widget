# Sobelz Embla Carousel برای Elementor

افزونهٔ وردپرس با یک ویجت مستقل برای Elementor رایگان و Pro. تمام فایل‌های Embla داخل افزونه هستند و هنگام استفاده هیچ کتابخانه‌ای از CDN دریافت نمی‌شود.

## نصب

1. وردپرس ۶٫۵ یا بالاتر، PHP نسخهٔ ۷٫۴ یا بالاتر و Elementor نسخهٔ ۳٫۲۰ یا بالاتر لازم است.
2. فایل `dist/sobelz-embla-carousel-widget-1.1.0.zip` را از «افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه» نصب و فعال کنید. برای ارتقا، تأیید کنید که نسخهٔ نصب‌شده با این بسته جایگزین شود.
3. در ویرایشگر Elementor عبارت **Sobelz Embla Carousel** را جست‌وجو کنید و ویجت را به صفحه اضافه کنید.
4. در بخش «اسلایدها» محتوا را وارد کنید. هر اسلاید می‌تواند تصویر، عنوان، توضیح و دکمه داشته باشد، یا یک قالب منتشرشدهٔ Elementor را نمایش دهد.
5. در «افزونه‌های Embla» قابلیت‌های مورد نیاز را فعال کنید. برای Autoplay، گزینهٔ «حرکت خودکار» را روی «پخش خودکار» بگذارید.

اگر زبان سایت فارسی باشد، کنترل‌ها و برچسب‌ها فارسی می‌شوند. جهت نمایش در حالت پیش‌فرض از جهت سایت گرفته می‌شود و قابل تغییر به RTL یا LTR است.

اگر نسخه‌ای با نام قدیمی `embla-elementor-widget` نصب کرده‌اید، ابتدا آن را غیرفعال و سپس نسخهٔ جدید را نصب و فعال کنید. شناسهٔ داخلی ویجت حفظ شده است و صفحه‌های قبلی می‌توانند از نسخهٔ جدید استفاده کنند.

## تنظیمات

- تعداد اسلایدهای قابل مشاهده و فاصلهٔ آن‌ها برای دستگاه‌های مختلف، با کنترل‌های واکنش‌گرای Elementor.
- محور افقی یا عمودی، ارتفاع نمای عمودی، تراز، حلقهٔ بی‌نهایت، گروه‌بندی، درگ آزاد، آستانهٔ درگ و مدت حرکت.
- **Autoplay:** فاصلهٔ زمانی، جابه‌جایی آنی، توقف در آخرین گروه، توقف روی اشاره‌گر یا بعد از تعامل.
- **Auto Scroll:** حرکت پیوسته با سرعت، جهت و تأخیر قابل تنظیم.
- **Auto Height:** ارتفاع متناسب با اسلایدهای قابل مشاهده در محور افقی.
- **Fade:** محوشدن میان اسلایدها، با نمایش یک اسلاید در هر نما.
- **Class Names:** کلاس‌های وضعیت Embla برای استایل سفارشی.
- **Wheel Gestures:** جابه‌جایی با چرخ ماوس و ترک‌پد، با انتخاب محور ورودی.
- فلش، نقاط ناوبری متناسب با گروه‌های اسکرول، نوار پیشرفت، دکمهٔ پخش/توقف و کلیدهای جهت‌نما، Home و End.
- تنظیم رنگ، تایپوگرافی، پس‌زمینه، کادر، سایه، گردی، فاصله‌ها، تصویر و ناوبری در تب استایل.

Autoplay و Auto Scroll دو حالت جایگزین هستند. Fade با Auto Scroll پیوسته ترکیب نمی‌شود. حرکت خودکار داخل ویرایشگر متوقف است تا ویرایش اسلایدها راحت باشد؛ نتیجه را در پیش‌نمایش صفحه یا صفحهٔ منتشرشده ببینید.

برای توقف موقت روی اشاره‌گر و ادامهٔ خودکار بعد از خروج، «توقف بعد از تعامل» را خاموش کنید. با فعال‌بودن این گزینه، بعد از تعامل باید دکمهٔ پخش را بزنید.

Embla در صورت کم‌بودن تعداد اسلایدها نسبت به تعداد قابل مشاهده، حلقه را خودکار غیرفعال می‌کند. تعداد اسلایدها را بیشتر یا تعداد قابل مشاهده را کمتر کنید.

## Loop Item المنتور پرو و کوئری پویا — نسخهٔ ۱٫۱٫۰

قالب Loop Item ظاهر هر آیتم را مشخص می‌کند؛ نتایج کوئری، پست‌هایی هستند که در آن قالب نمایش داده می‌شوند. قالب به‌تنهایی فهرست پست‌ها را ذخیره نمی‌کند.

1. در Elementor Pro از «قالب‌ها ← پوسته‌ساز ← Loop Item» یک قالب بسازید و منتشر کنید. عنوان، تصویر شاخص، پیوند و فیلدهای سفارشی را با تگ‌های پویا به آن وصل کنید.
2. در ویجت Embla، «منبع محتوا» را روی **کوئری پویا** قرار دهید.
3. «قالب نمایش آیتم‌های کوئری» را روی **قالب Loop Item المنتور پرو** بگذارید و قالب را انتخاب کنید.
4. در بخش **کوئری** نوع نوشته، تعداد، ترتیب و فیلترها را تنظیم کنید. هر نتیجه با دادهٔ خودش در قالب رندر می‌شود.

برای استفاده بدون Pro، گزینهٔ **کارت آمادهٔ نوشته** را انتخاب کنید. عنوان، تصویر شاخص، خلاصه و پیوند از نتایج کوئری گرفته می‌شوند. حالت اسلایدهای دستی نسخهٔ قبلی هم در دسترس است.

منابع کوئری:

- **نوشته‌ها / نوع نوشتهٔ سفارشی:** پست‌ها، برگه‌ها یا نوع نوشتهٔ عمومی سایت؛ فیلتر با شناسهٔ دسته‌ها، نویسنده و پست‌ها، حذف آیتم‌ها، تعداد، ردکردن از ابتدا و مرتب‌سازی.
- **آرشیو جاری / کوئری اصلی:** پیروی از کوئری اصلی صفحه یا آرشیو با همان فیلترها، ترتیب و صفحه‌بندی. کوئری اصلی تغییر داده نمی‌شود.
- **نوشته‌های مرتبط:** پست‌های دارای دسته یا اصطلاح مشترک با پست جاری، بدون خود پست. نبود اصطلاح مشترک به معنی نبود نتیجه است.
- **انتخاب با شناسه:** شناسه‌ها را با ویرگول انگلیسی وارد کنید. برای حفظ ترتیب آن‌ها، مرتب‌سازی را روی «ترتیب شناسه‌های واردشده» بگذارید.

در هر ویجت حداکثر ۱۰۰ پست عمومی و بدون رمز نمایش داده می‌شود. نوع نوشتهٔ محصول در صورت ثبت توسط WooCommerce در فهرست موجود است؛ قواعد خاص فروشگاه، مانند پنهان‌بودن از کاتالوگ یا موجودی، باید در کوئری اعمال شوند.

### Query ID و کوئری‌های سفارشی

برای نمونه، Query ID را `featured_items` بگذارید و کد زیر را در افزونهٔ اختصاصی سایت یا Code Snippets قرار دهید:

```php
add_action( 'elementor/query/featured_items', function ( $query, $widget ) {
    $query->set( 'meta_query', [
        [ 'key' => 'is_featured', 'value' => '1' ],
    ] );
    $query->set( 'posts_per_page', 8 );
}, 10, 2 );
```

برای فیلدهای رابطه‌ای که شناسهٔ پست‌ها را ذخیره می‌کنند:

```php
add_action( 'elementor/query/related_items', function ( $query ) {
    $ids = wp_parse_id_list( get_post_meta( get_the_ID(), 'related_items', true ) );
    $query->set( 'post__in', $ids ?: [ 0 ] );
    $query->set( 'orderby', 'post__in' );
} );
```

اگر افزونه‌ای مانند ACF فیلد رابطه‌ای را به شکل آرایهٔ اشیای پست برمی‌گرداند، ابتدا شناسه‌ها را از آن استخراج کنید. همچنین فیلتر `eew/query_args` سه ورودی آرگومان‌های کوئری، ویجت و تنظیمات نهایی را برای سفارشی‌سازی دریافت می‌کند. این ویجت قرارداد [Query ID المنتور](https://developers.elementor.com/docs/hooks/custom-query-filter/) را اجرا می‌کند؛ اتصال خودکار به فیلتر AJAX یا صفحه‌بندی ویجت Loop Grid دیگر انجام نمی‌شود.

### فاصلهٔ اتصال انتها و ابتدای حلقه

در «رفتار کروسل»، **حلقهٔ بی‌نهایت** را روشن کنید. در «چیدمان»، گزینهٔ **فاصلهٔ اتصال آخرین اسلاید به اولین** اضافه شده است:

- خالی: همان مقدار «فاصلهٔ اسلایدها» اعمال می‌شود.
- مقدار مشخص: فاصلهٔ اتصال را مستقل تعیین می‌کند؛ صفر هم معتبر است.
- کنترل واکنش‌گراست و در محور عمودی و RTL هم کار می‌کند.

این اصلاح برای اسلایدهای دستی، کارت‌های کوئری و Loop Item مشترک است. در Fade فاصله کاربردی ندارد. علت و روش اصلاح با راهنمای [فاصله‌ها در Embla](https://www.embla-carousel.com/docs/v8/guides/slide-gaps) مطابقت دارد.

## فایل‌ها و توسعه

هسته و افزونه‌های رسمی Embla نسخهٔ ثابت **۸٫۶٫۰** هستند؛ Wheel Gestures نسخهٔ **۸٫۰٫۲** است. مجوزها و هش فایل‌ها همراه بسته قرار دارند. در سایت نیازی به Node.js یا نصب وابستگی نیست.

برای توسعهٔ محلی:

```sh
npm ci
npm run vendor
npm run test:php
npm test
npm run test:wordpress
npm run package
```

دستور vendor فقط برای توسعه است و به اینترنت نیاز دارد. بستهٔ نصب فقط فایل‌های اجرایی را شامل می‌شود. آزمون WordPress از Playground و Elementor واقعی استفاده می‌کند و در اولین اجرا بسته‌های تست را دریافت می‌کند.

آزمون‌های مرورگر به Chromium نیاز دارند؛ در صورت متفاوت‌بودن مسیر، متغیر `CHROMIUM_PATH` را تنظیم کنید. روی شبکه‌های نیازمند پروکسی می‌توانید دستور آزمون WordPress را با `NODE_USE_ENV_PROXY=1` اجرا کنید.

API هر نمونه از طریق `document.querySelector('.eew').emblaApi` در دسترس است. رویداد `eew:ready` نیز API را در `event.detail.api` ارسال می‌کند.

```js
document.addEventListener('eew:ready', function (event) {
  const embla = event.detail.api;
  console.log(embla.plugins());
});
```

برای راهنمای API، [مستندات رسمی نسخهٔ ۸ Embla](https://www.embla-carousel.com/docs/v8/get-started/cdn) را ببینید.
